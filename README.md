# Fundament — німецька з опорою

Легка програма українською для вивчення німецької: 37 граматичних нагадувалок A1–C1, словник і друк на A4 / A5.

Онлайн: https://deutsch-fundament-vital.vitalii-gyliaiev.chatgpt.site

## Можливості

- Добірка аркушів за рівнем та пошук правил.
- Кольорові підказки для родів і відмінків.
- Переклади, приклади та пояснення, які можна вмикати окремо.
- Друк одного аркуша A4 або двох A5.
- Налаштування й обрані слова зберігаються локально у браузері.

## Запуск

Відкрийте `index.html` у браузері. Складання та встановлення залежностей не потрібні.

Для локального HTTP-сервера, якщо встановлений Python:

```sh
python -m http.server 4173
```

Після цього відкрийте http://localhost:4173.

## Структура

`index.html`, `styles.css` та JavaScript-файли — статична програма. `GRAMMAR-AUDIT.md` містить огляд тем і навчальні джерела.
